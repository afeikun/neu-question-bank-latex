# 基于LLM视觉转换的东北大学机考题库LaTeX版

目前可能尚存不少转换错误，欢迎pr。

共8203题：高等数学4471、线性代数835、概率论1601、复变函数1296。数据按科目、章节、题号放在data/，保留转换后的JSON原内容。含原图版每题目录附source/原图，纯JSON版不包含原图。已有JSON中21题解析未补齐；另有40道高数原图404、尚未生成JSON，分别见下文。

## 两种 release 的使用方式

| 压缩包 | 内容 | 适合用途 |
|---|---|---|
| [neu-question-bank-json.zip](https://github.com/afeikun/neu-question-bank-latex/releases/latest/download/neu-question-bank-json.zip) | JSON数据、离线渲染demo和本说明 | 使用题库、导入自己的程序或快速预览 |
| [neu-question-bank-with-source.zip](https://github.com/afeikun/neu-question-bank-latex/releases/latest/download/neu-question-bank-with-source.zip) | 上述全部内容，另附每题source/原图与原始错误页 | 对照原图核查转换、修正问题和提交PR |

**纯JSON版：** 解压后，data/中按科目、章节、题号保存question.json，可直接读取或导入自己的程序。双击demo/index.html，点击“选择JSON”，选择题目文件即可离线查看公式；也可同时选择多份JSON。此版不含原始图片。

**含原图版：** JSON的读取和demo使用方式与纯JSON版相同。需要核对时，在同一题的source/中打开原图，对照question.json的题干、选项、答案和解析。图片按原HTML顺序编号；损坏的404内容以.404.html保存。尚未生成JSON的40题只保留题号目录和source/，不要将其当作已经转换的题目。

两版的8203份题目JSON完全相同，区别仅在于是否附带原始资料。下文的未完成与源图损坏说明适用于两版。

## 渲染方式

双击demo/index.html即可离线打开，点击“选择JSON”，选择data/中的question.json预览。可同时选多份JSON，也支持题目数组。不需要安装依赖或启动服务。

demo/render.js演示Markdown与KaTeX公式渲染，demo/app.js演示读取题干、选项、答案和解析。公式支持单美元符号、双美元符号以及圆括号/方括号反斜杠定界符。先识别公式，再解析Markdown，避免矩阵行间符号和下标被改写。HTML输出经DOMPurify处理。

每题七字段：question_type、stem_md、options_json、answer_json、analysis_md、search_text、sort_order。选项与答案为JSON数组/对象；search_text是检索缓存，不需要展示。题号和sort_order仅在章节内有意义。

静态demo只带渲染必需的第三方浏览器库和字体，许可证在demo/vendor/LICENSES.txt。没有桌面应用或其它项目模块。


## 每题原始图片（仅含原图版）

每题目录中的source/保留原HTML图片的图像内容，未截图、裁切或重新压缩。公开发布前已去除作者、账户名等隐藏元数据，图像像素保持不变。part_01、part_02等按原HTML中的图片顺序排列，通常依次为题干、四个选项、解析；部分题的一栏含多张图。

原文件中实际为404错误页面的内容保存为part_XX.404.html，保留原始内容，不冒充正常图片。少数其它错误页面同样以error.html保存。

对于尚未生成JSON的40题，也保留对应题号文件夹和source/，但没有编造question.json。
